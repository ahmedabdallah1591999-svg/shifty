# شيفتي (Shifty)

تطبيق ويب بسيط للموبايل: كل موظف يختار اسمه ويشوف شيفتات الأسبوع، ويقدر يفعّل تنبيه بمعاد الشيفت.

## التشغيل
- افتح `index.html` من أي استضافة ثابتة (GitHub Pages مثلًا).
- جدول الشيفتات **مش موجود في الكود**: كل مستخدم يستورده بنفسه (لصق JSON أو رابط مشاركة خاص). مفيش أي بيانات موظفين في المستودع ده.
- كل البيانات بتتخزن محليًا على الجهاز (localStorage) — مفيش سيرفر ولا حسابات.

## صيغة ملف الجدول (JSON)
```json
{
  "name": "اسم الجدول",
  "week": "٢١–٢٧ نوفمبر",
  "employees": [
    {"name": "الاسم", "sat": "9-5", "sun": "off", "mon": "2-10", "tue": "online", "wed": "9-5", "thu": "؟", "fri": "off"}
  ]
}
```
- الخلايا: `9-5` (من ٩ لـ٥)، `off` أجازة، `online` شغل من البيت، `؟` غير واضح.
- الخلايا غير الواضحة بتظهر «غير واضح» ومش بتتجدول لها تنبيهات لحد ما تتأكد.

## الإشعارات (وضع تجريبي)
تنبيهات المتصفح بتعتمد على Periodic Background Sync: ميزة تجريبية في كروم فقط، ومش مضمونة المعاد لما المتصفح يكون مقفول. للتنبيه الدقيق فيه نسخة أندرويد أصلية (APK) منفصلة.

## الملفات
- `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, الأيقونات — تطبيق ويب كامل بدون أي اعتماديات خارجية.
